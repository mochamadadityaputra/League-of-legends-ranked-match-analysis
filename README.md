# League-of-legends-ranked-match-analysis
Data-driven project that analyzes ranked match performance in LoL to identify key factors that influence team victory. This project applies Exploratory Data Analysis (EDA) and Machine Learning (Gradient Boosting Classifier) to evaluate the impact of game objectives such as tower kills, inhibitors, and baron control on winning probability.
